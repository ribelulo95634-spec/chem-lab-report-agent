## 三、实验原理

### 3.1 浊点法测定溶解度曲线

乙醇分别与环己烷、水具有较好的互溶性，而水在环己烷中的溶解度较小。向澄清的乙醇—环己烷均相混合物中缓慢滴加水，当体系组成越过两相区边界时，会因生成微小分散液滴而出现稳定浑浊。记录此时三种物质的加入质量，可求得一个浊点组成。改变初始乙醇和环己烷比例并重复测量，即可获得一系列溶解度曲线实验点。

组分质量分数：

`w_i = m_i / (m_A + m_B + m_W) × 100%`

其中 A、B、W 分别代表乙醇、环己烷和水；每个数据点应满足 `w_A + w_B + w_W ≈ 100%`。

### 3.2 折射率法测定联结线

恒温恒压下，三组分两液相平衡体系按相律有 `F = C - P = 3 - 2 = 1`。体系充分搅拌并静置分层后，分别测量上层油相和下层水相的折射率，再由同温度下的“浓度—折射率”标准曲线换算两相组成。在三元相图中连接同一平衡数据组的两相组成点，即得到一条联结线。

### 3.3 分配系数与选择性系数（待核对原图）

本报告暂以乙醇为溶质 A、环己烷为载体 B、水相为萃取相 E、油相为萃余相 R，按常用定义写为：

- `K_A = w_A^E / w_A^R`
- `K_B = w_B^E / w_B^R`
- `β = (w_A^E / w_B^E) / (w_A^R / w_B^R) = K_A / K_B`

一般而言，`K_A` 越大说明乙醇越倾向进入水相；`β > 1` 且数值越大，说明水对乙醇相对于环己烷的选择性越好。**原讲义公式图片未成功提取，上述相别和符号在提交前必须复核。**

## 六、计划实验步骤

1. 开启恒温水浴和加热，使液液平衡釜温度稳定；记录室温、大气压力、设定温度和实际温度。
2. 采用差量法向平衡釜加入约 5–6 mL 环己烷：记录盛液容器转移前质量 `G₂` 和转移后质量 `G₁`，加入质量为 `G₂-G₁`。
3. 同法加入约 10–12 mL 无水乙醇，保存两次原始称量值，不只记录差值。
4. 磁力搅拌 2–3 min，使体系混合均匀；预期为澄清单液相。
5. 称量装有约 2–3 mL 去离子水的注射器。缓慢滴加水，接近终点时逐滴加入；首次出现稳定浑浊后立即停止，吸回针尖液滴并复称，以差值求加水质量。改变乙醇/环己烷用量，重复获得系列浊点。
6. 在一个浊点体系中再加入 1–2 mL 水，搅拌 1–2 min，停止后静置 15–20 min。
7. 待相界面清晰后，用洁净注射器分别取上层油相和下层水相，测折射率；由标准曲线换算两相组成并配对记录。
8. 再追加 1–2 mL 水并重复步骤 6–7，共取得 3–4 组数据，目标绘制 3 条联结线。
9. 停止设备；分类回收废液，清洗平衡釜、注射器和折射仪棱镜，归档原始记录。

停止并请求教师确认的情形：温度持续不稳；首次浑浊已明显过量；上下相无法清晰分层；折射仪未校准；两相样品编号无法配对；废液类别不明确。

## 八、数据处理与作图计划

### 8.1 基础计算

1. 差量称量：`m_i = m_转移前 - m_转移后`。
2. 浊点组成：分别计算 `w_A`、`w_B`、`w_W`，保留统一有效数字。
3. 完整性检查：每行三组分质量分数之和应接近 100%；若偏差明显，回查称量、转移、挥发和录入。
4. 由折射率标准曲线得到上、下相组成；标准曲线的温度、单位和适用区间必须与样品一致。
5. 按核对后的公式计算每组 `K_A`、`K_B` 和 `β`，并保留相别、单位基准和中间值。

### 8.2 Origin 三元相图操作计划

1. 建立三列数据：乙醇、环己烷、水的质量百分数；先检查每行合计为 100%。
2. 导入讲义附录的 25 °C 参考数据，绘制参考溶解度曲线；参考数据与实测数据必须使用不同系列和图例。
3. 将实测浊点以散点叠加，不把实验点改写成参考数据。
4. 将同一数据组的上、下相组成点配对连接，形成联结线；不得跨组连接。
5. 图中注明三顶点组分、质量百分数、实验温度、图例、数据来源和 Origin 版本。

## 九、预期现象（不是实验结果）

- 乙醇与环己烷充分混合后，体系预期为澄清均一液相。
- 缓慢加水越过相界时，预期由澄清转为首次稳定浑浊。
- 继续加水、搅拌并充分静置后，预期形成上层油相和下层水相，界面逐渐清晰。

实验时必须按真实观察记录颜色、澄清度、乳化、分层速度、界面位置和异常；不得把上述预期直接抄作实验现象。

## 十、预习思考题

1. **为什么会液液分相？** 当某些总体组成下均相混合物的吉布斯自由能高于分成两个不同组成液相后的总自由能时，体系通过分相降低自由能；两相平衡时各组分在两相中的化学势分别相等。
2. **为何浑浊可指示相界？** 刚进入两相区时产生微小分散液滴，对可见光发生散射，使透明体系变浑浊，因此首次稳定浑浊可作为越过双结线的实验信号。
3. **如何用 K 和 β 评价萃取剂？** K 描述目标溶质在两相间的偏好；β 比较目标溶质与载体的相对分配。通常希望目标溶质的 K 较大且 β 明显大于 1，但还应结合互溶度、相分离速度、安全性和经济性评价。
4. **温度和压力有何影响？** 温度会改变活度系数和相互溶解度，从而移动两相区边界和联结线；在通常实验压力范围内，压力对凝聚相液液平衡影响一般小于温度，但仍应记录实验压力。
5. **主要误差来源是什么？** 浊点终点过量、乙醇/环己烷挥发、差量转移残留、温度波动、混合或静置不足、乳化、取样扰动与交叉污染、折射仪未校准、标准曲线温度不匹配、样品编号错配以及有效数字处理不一致。
