## 2. 实验原理

### phenanthroline_colorimetry

Fe2+ 与邻菲啰啉形成橙红色络合物，在 510 nm 测量吸光度并建立校准关系。

公式：`Fe2+ + 3 Phen -> [Fe(Phen)3]2+`；`A = a + b c`；`c = (A - a) / b`
适用假设：标准与样品显色和测量条件一致；样品响应位于校准范围；线性模型经残差检查
来源：hj_t_345_2007、huhst_teaching_guide、competition_public_data、nist_calibration

## 6. 数据处理与专业软件计划

### A = a + b c

处理等级：**automatic**；方法：`linear_regression`；输入：concentration_ug_per_ml, absorbance；要求输出：calibration_model, 图表:calibration_curve, 图表:calibration_residuals。
### c = (A - a) / b

处理等级：**automatic**；方法：`inverse_calibration`；输入：absorbance；要求输出：calculated_concentration_ug_per_ml。
### RSD = s / mean × 100%

处理等级：**automatic**；方法：`rsd`；输入：calculated_concentration_ug_per_ml；要求输出：unknown_rsd_percent。
### content(mg/10mL) = c_measured(ug/mL) × 500 × 10 / 1000

处理等级：**automatic**；方法：`dilution`；输入：calculated_concentration_ug_per_ml；要求输出：product_content_mg_per_10ml。
### recovery = (mean_spiked - mean_unspiked) / spike × 100%

处理等级：**automatic**；方法：`recovery`；输入：spike_ug_per_ml, reported_concentration_ug_per_ml；要求输出：recovery_percent。
### Origin 线性拟合与图表导入

处理等级：**guided**；方法：`Origin Linear Fit`；输入：concentration_ug_per_ml, absorbance；要求输出：参数表, 拟合范围, 残差图, 校准曲线, 软件版本。
- 将标准浓度设为 X、吸光度设为 Y，保留样品 ID 和单位列。
- 选择 Analysis > Fitting > Linear Fit；是否固定截距必须服从指导书，默认不固定。
- 在报告中输出斜率、截距、R²、参数标准误、拟合范围和残差图。
- 导出参数表为 CSV/XLSX，图表为 PNG/SVG/PDF；保存 .opju 仅作归档，第一版不解析。
- 导入 Agent 后核对样品 ID、单位、模型、拟合范围及图表中的参数是否一致。
