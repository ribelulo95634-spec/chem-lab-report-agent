# 大学化学实验模块与标准流程

## 1. 文档用途

本目录用于确定通用化学实验 Agent 的代表性覆盖范围，并为后续 `ExperimentSpec`、数据字段、计算工具和图表工具设计提供样本。

这里的“标准流程”是用于软件建模的高层流程，不替代学校实验指导书。实际试剂用量、浓度、温度、时间、仪器参数、个人防护和废液分类必须以导师审核后的指导书及本校实验室规定为准。

逐实验的完整报告流程已进一步拆分到 `docs/实验模块详解/`:

- `00_统一实验报告结构.md`
- `01_基本操作与化学原理.md`
- `02_无机化学实验.md`
- `03_分析化学实验.md`
- `04_有机化学实验.md`
- `05_物理化学实验.md`
- `06_仪器分析实验.md`

高校课程体系通常包括无机、分析、有机、物理化学和仪器分析等模块；部分学校还单独设置基本技能、综合实验和高分子实验。本项目第一批覆盖六个基础模块，每个模块选择三个代表性实验。

## 模块 A: 基本操作与化学原理

### A1. 容量器皿使用与标准溶液配制

**目的**: 掌握称量、溶解、定量转移、定容和稀释，并建立浓度与不确定度记录习惯。

**标准流程**:

1. 阅读指导书，确认目标浓度、溶液体积、试剂纯度和安全要求。
2. 检查天平、容量瓶、移液管及标签状态。
3. 计算理论取样量或稀释体积，并由人工确认单位和有效数字。
4. 按指导书完成称量、溶解、定量转移、定容和混匀。
5. 记录实际称量值、器皿规格、温度、批次和异常情况。
6. 标记溶液名称、浓度、日期和责任人，按规定保存或处置。

**主要数据**: 理论量、实际质量、纯度、定容体积、稀释倍数、器皿允差。

### A2. 醋酸电离常数与电离度测定

**目的**: 根据不同浓度醋酸溶液的 pH，计算电离度和表观电离常数。

**标准流程**:

1. 确认温度、浓度系列和 pH 计校准要求。
2. 使用合适的标准缓冲液校准仪器，并记录斜率或校准状态。
3. 按规定顺序测量各浓度溶液，待读数稳定后记录 pH 和温度。
4. 每个样品进行规定次数的平行测定，并完成电极清洗。
5. 由程序将 pH 转换为氢离子浓度，计算电离度和电离常数。
6. 比较不同浓度结果，讨论活度、温度和仪器误差影响。

**主要数据**: 标称浓度、pH、温度、平行次数、校准记录。

### A3. 化学反应速率与温度影响

**目的**: 通过可观测终点或连续信号研究浓度、温度对反应速率的影响。

**标准流程**:

1. 明确反应体系、观测指标、变量组和固定条件。
2. 分别准备浓度组或温度组，检查计时与恒温设备。
3. 按统一触发条件开始反应并同步计时或采集信号。
4. 记录终点时间或时间序列，每组完成平行实验。
5. 计算表观速率或速率常数，绘制变量与速率的关系。
6. 如有多温度数据，按指导书进行 Arrhenius 拟合并报告适用范围。

**主要数据**: 配比、温度、时间、信号、平行组、环境条件。

## 模块 B: 无机化学实验

### B1. 硝酸钾的制备与纯化

**目的**: 练习溶解度差异、热过滤、结晶、抽滤和干燥等基本操作。

**标准流程**:

1. 核对反应原理、理论计量关系和试剂危害。
2. 按指导书完成溶解和反应，并记录实际投料。
3. 在规定条件下除去不溶物或副产物。
4. 通过浓缩和冷却形成晶体，记录结晶现象。
5. 完成固液分离、洗涤和干燥，得到恒定或规定状态的产品。
6. 称量产品，计算理论产量、实际产量和产率，评价纯度或外观。

**主要数据**: 投料质量、纯度、滤液或结晶状态、产品质量、干燥条件。

### B2. 硫酸亚铁铵的制备

**目的**: 完成复盐制备，训练反应条件控制、浓缩结晶和产品质量评价。

**标准流程**:

1. 根据指导书确定目标产物和限制反应物，完成理论产量计算。
2. 检查防护、通风和废液要求，记录试剂实际用量。
3. 按指导书完成前体反应、过滤和溶液条件调整。
4. 加入另一组分并完成浓缩、冷却和结晶。
5. 分离、洗涤和干燥晶体，避免不必要的氧化或污染。
6. 计算产率，并按指导书进行外观、离子反应或其他质量检验。

**主要数据**: 投料量、反应现象、溶液状态、产品质量、质量检验结果。

### B3. 电离平衡、沉淀平衡与沉淀转化

**目的**: 观察 pH、浓度和配位作用对沉淀生成、溶解与转化的影响。

**标准流程**:

1. 将各反应拆分为独立编号的小试体系，建立空白和对照。
2. 按指定顺序加入试剂，记录颜色、浑浊、沉淀和溶解变化。
3. 改变一个变量，例如 pH、浓度或配体，其他条件保持一致。
4. 对可测量体系记录 pH、吸光度或电导等定量信号。
5. 根据离子方程式、平衡常数和条件变化解释现象。
6. 对无法量化的观察保留原始文字或照片证据，不自动虚构数值。

**主要数据**: 试剂顺序、条件变量、现象、pH 或仪器信号、照片索引。

## 模块 C: 分析化学实验

### C1. 酸碱标准溶液标定与未知酸测定

**目的**: 掌握标准溶液标定、滴定终点判断和平行测定。

**标准流程**:

1. 检查滴定管、移液管和容量器皿，确认分析反应与指示终点。
2. 配制待标定溶液，记录基准物质质量、纯度和处理状态。
3. 完成粗测以确定滴定范围，再进行规定次数的平行标定。
4. 根据一致的终点判据记录初读数、末读数和有效体积。
5. 计算标准溶液浓度，检查平行结果是否达到允差。
6. 使用已标定溶液测定未知样，并报告含量、精密度和主要误差来源。

**主要数据**: 基准物质量、纯度、滴定读数、空白、样品量、平行测定值。

### C2. EDTA 配位滴定测定水硬度

**目的**: 使用配位滴定测定水中钙镁总量，并理解 pH、掩蔽和指示剂条件。

**标准流程**:

1. 标定 EDTA 溶液，确认缓冲体系、指示剂和终点颜色定义。
2. 量取水样，按指导书加入缓冲液及必要辅助试剂。
3. 先做粗测，再进行平行滴定，记录初末读数和终点现象。
4. 同步完成空白实验，并将空白修正独立保存。
5. 根据 EDTA 浓度、校正体积和样品体积计算硬度。
6. 按指定单位报告结果，并检查是否超出方法线性或适用范围。

**主要数据**: EDTA 浓度、水样体积、滴定体积、空白、单位和换算基准。

### C3. 高锰酸钾法测定铁或过氧化氢

**目的**: 掌握氧化还原标准溶液标定和自指示滴定分析。

**标准流程**:

1. 确认被测物、介质、化学计量关系和可能的干扰。
2. 配制并标定滴定剂，记录基准物和所有读数。
3. 按指导书处理样品并完成必要的空白或预处理。
4. 以统一的终点保持时间和颜色标准进行平行滴定。
5. 完成空白修正，按反应计量计算被测物含量。
6. 检查滴定结果一致性，讨论光照、温度、杂质和终点判断影响。

**主要数据**: 标定数据、样品量、滴定体积、空白、化学计量系数。

## 模块 D: 有机化学实验

### D1. 重结晶与熔点测定

**目的**: 掌握固体有机物纯化，并用熔程评价纯度。

**标准流程**:

1. 根据指导书和安全数据选择适用溶剂，确认加热与通风要求。
2. 记录粗品质量，完成溶解、必要的脱色或热过滤。
3. 控制冷却和结晶过程，记录是否出现油析或异常晶型。
4. 完成固液分离、少量洗涤和充分干燥。
5. 记录纯化产品质量，计算回收率。
6. 测定熔程并与可信参考值比较，结合外观判断纯化效果。

**主要数据**: 粗品质量、溶剂信息、产品质量、熔点起止值、异常现象。

### D2. 常压蒸馏与沸点测定

**目的**: 训练蒸馏装置、温度记录和馏分划分，理解沸点与组成关系。

**标准流程**:

1. 经教师确认装置、热源、冷却和防火要求，严禁密闭加热。
2. 记录样品体积或质量，检查温度计位置和装置气密通畅性。
3. 按指导书缓慢加热，稳定记录温度、时间和累计馏出量。
4. 根据温度平台或规定区间划分馏分，不追求蒸干。
5. 停止加热并按规定冷却、拆卸和处置残液。
6. 绘制温度与馏出量关系，报告主馏分、回收率和损失来源。

**主要数据**: 初始量、时间、温度、馏出量、馏分范围、回收量。

### D3. 乙酰水杨酸的制备与纯化

**目的**: 训练有机合成、结晶纯化、产率计算和产品表征。

**标准流程**:

1. 核对反应式、限制试剂、理论产量、危险物和废液类别。
2. 按经审核的指导书搭建反应体系并控制反应条件。
3. 完成反应后按规定淬灭或转化剩余试剂，并诱导结晶。
4. 分离、洗涤、重结晶和干燥产品。
5. 称量产品，计算粗产率或纯化后产率。
6. 使用熔点及指导书指定的方法评价纯度，讨论副反应和损失。

**主要数据**: 投料量、纯度、反应条件、粗品和纯品质量、熔程或光谱结果。

## 模块 E: 物理化学实验

### E1. 乙酸乙酯皂化反应速率常数的测定

**目的**: 用电导法追踪反应进程，计算二级反应速率常数。

**标准流程**:

1. 确认动力学模型、初始浓度、恒温条件和采样时间表。
2. 校验电导仪和温控状态，分别记录起始或终态参考信号。
3. 在统一混合时刻启动计时，并连续记录电导率与时间。
4. 重复实验或完成另一温度组，保留全部原始时间序列。
5. 按指导书转换变量并进行线性或非线性拟合。
6. 报告速率常数、拟合优度和残差；多温度时可进一步计算活化能。

**主要数据**: 温度、初始浓度、时间、电导率、参考信号、重复组。

### E2. 最大泡压法测定表面张力

**目的**: 测定不同浓度溶液的表面张力，并研究界面吸附规律。

**标准流程**:

1. 确认温度、浓度系列、仪器常数和毛细管清洁状态。
2. 使用参考液完成校准或仪器常数确认。
3. 按浓度顺序测量最大压力差，每个样品完成平行读数。
4. 控制气泡形成条件和恒温状态，记录异常气泡或污染。
5. 计算各浓度表面张力并绘制浓度关系图。
6. 在模型适用时计算表面过量或分子占据面积，并报告假设。

**主要数据**: 浓度、温度、压力差、仪器常数、参考液值、平行读数。

### E3. 二组分固液相图测绘

**目的**: 通过步冷曲线确定相变温度并绘制二元体系相图。

**标准流程**:

1. 确认组成系列、热分析设备、温度传感器校准和高温防护。
2. 为各组成样品建立唯一编号并记录实际组成。
3. 按统一程序采集冷却过程的温度和时间序列。
4. 从平台、拐点或导数特征中提取相变温度，并保留人工复核。
5. 将相变温度对组成作图，识别液相线和共晶特征。
6. 报告共晶温度、组成估计、拟合或读图方法及不确定度。

**主要数据**: 样品组成、时间、温度、校准记录、相变点及判定方法。

## 模块 F: 仪器分析实验

### F1. 紫外可见分光光度法测定铁

**目的**: 建立标准曲线并测定未知样中的铁含量。

**标准流程**:

1. 确认显色体系、波长、反应时间、空白和线性范围。
2. 配制标准系列、空白和样品，记录所有稀释过程。
3. 完成仪器预热、基线或空白校正，并记录仪器状态。
4. 测量标准系列和样品吸光度，必要时进行平行测定。
5. 对标准数据进行线性回归，检查残差和异常点。
6. 由回归方程计算样品浓度，经稀释倍数换算并报告不确定度。

**主要数据**: 标准浓度、吸光度、波长、空白、样品吸光度、稀释链。

### F2. 离子选择电极测定氟离子

**目的**: 建立电位与对数浓度关系，并测定未知样品中的氟离子。

**标准流程**:

1. 确认电极状态、标准系列、离子强度调节和温度要求。
2. 活化或检查电极，测量空白与标准系列的稳定电位。
3. 绘制电位对浓度对数的校准曲线，检查斜率和线性范围。
4. 以相同基体条件测量样品，必要时采用标准加入法。
5. 由回归模型计算样品浓度并完成稀释换算。
6. 报告校准斜率、响应稳定性、检出范围和可能干扰。

**主要数据**: 标准浓度、电位、温度、稳定时间、样品电位、加标信息。

### F3. 气相色谱分析混合醇

**目的**: 依据保留时间进行定性，并使用归一化法或校准法进行定量。

**标准流程**:

1. 由教师或仪器负责人确认方法文件、载气、温度程序和进样要求。
2. 检查仪器状态、空白和系统适用性，等待基线稳定。
3. 采集标准品或混合标准色谱图，建立保留时间和响应信息。
4. 按统一方法采集样品及平行进样数据。
5. 完成峰识别、积分复核和必要的校正因子处理。
6. 计算各组分含量，报告分离度、重复性、积分修改和异常峰。

**主要数据**: 方法版本、保留时间、峰面积、峰高、分离度、校正因子、进样序号。

## 2. 统一数据处理流水线

所有模块使用同一套数据处理主流程，实验差异通过 `ExperimentSpec`、公式白名单和图表配置表达。

### 第 1 层: 原始数据层

- 保留仪器原始文件、手工记录、照片和导入时间。
- 每条记录包含实验 ID、样品 ID、重复编号、操作者、单位和来源。
- 原始数据只追加，不直接覆盖；修正值单独记录原因和审批人。

### 第 2 层: 结构与质量校验

- 校验必填字段、数据类型、单位、合理范围和重复数。
- 检查样品编号、时间顺序、稀释链、空白和校准信息是否完整。
- 将问题分为阻断错误、需确认警告和普通提示。
- 不自动删除异常值；异常值必须保留原值、判定规则和处理决定。

### 第 3 层: 预处理

- 完成空白扣除、质量或体积修正、稀释倍数换算和单位统一。
- 仪器数据可包含基线修正、峰积分或信号平滑，但必须保存参数与前后版本。
- 只有在 `ExperimentSpec` 明确允许时才能应用对应预处理操作。

### 第 4 层: 确定性计算

- 基础统计: 均值、标准差、相对标准偏差、置信区间。
- 化学计算: 物质的量、浓度、化学计量换算、产率、回收率和滴定含量。
- 模型计算: 线性回归、标准加入、动力学拟合、Arrhenius 拟合和相变点提取。
- 每个结果保存公式 ID、输入值、单位、有效数字规则和程序版本。

### 第 5 层: 质量控制

- 检查平行测定精密度、标准曲线线性、残差和校准漂移。
- 将空白、标准样、加标回收、系统适用性和对照结果纳入判定。
- 可疑值检验仅提供证据和建议，是否剔除需要人工确认。
- 超出方法范围的样品不得强行外推，应提示稀释、重测或人工处理。

### 第 6 层: 图表生成

- 默认生成带名称和单位的坐标轴、图例、样品点和必要的误差棒。
- 拟合图同时显示模型、参数、拟合优度和残差图。
- 时间序列保留原始点；色谱和光谱保留原始信号与处理版本。
- 图表文件记录数据集 ID、配置版本和生成时间，保证可追溯。

### 第 7 层: 结果与报告审查

- 自动核对正文数字是否与计算结果一致。
- 自动核对图表、表格、单位、有效数字和样品名称。
- 将事实、计算结果、解释和推测分开标记。
- 对缺失信息、超范围结果和未通过质控的结论禁止静默生成。
- 最终报告由用户人工审核后导出。

## 3. 对通用 Agent 的能力映射

第一批通用能力应覆盖:

- 表格与时间序列导入
- 单位和稀释链处理
- 平行数据统计
- 滴定与产率计算
- 标准曲线和线性回归
- 动力学拟合
- 常见二维作图及误差棒
- 数据、图表和正文一致性检查
